# Hello World Example

This is the recommended starting point for new users of neobbs.

If you are trying neobbs for the first time, start here.

This example demonstrates the smallest possible neobbs application.

It shows how to:
- create an engine
- register a route
- connect a renderer
- wire stdin for input

## Run

```bash
node index.js
```

## Expected Output

```
────────────────────────────────────────
 Hello World
────────────────────────────────────────

Welcome to neobbs.

────────────────────────────────────────
>>
```

Press `Ctrl+C` to exit.
